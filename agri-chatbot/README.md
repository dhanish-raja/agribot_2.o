This folder contains the complete multi-tier source code for **AgriBot 2.0**:
- **`frontend/`**: Enterprise React 18 + TypeScript + Vite UI with full ChatGPT & Gemini feature parity.
- **`ai-service/`**: Python FastAPI microservice providing vector search, 3-tier routing, and Gemini 2.5 Flash grounded generation.
- **`backend/`**: Optional Spring Boot 3 Java Gateway for enterprise API management.
- **`data/`**: Verified 5-crop agricultural knowledge records (1,514 records) and embedded Qdrant storage.

For full architectural documentation, live deployment links, and API specifications, see the [Root README](../../README.md).
